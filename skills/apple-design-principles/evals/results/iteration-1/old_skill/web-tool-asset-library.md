## 一句话结论
Crate 的核心问题不是视觉，而是「诚实」和「看不见的地方」：示例数据、数字对不上、承诺与能力不一致会直接伤害信任；最关键的改动是去掉假数据、给危险操作加保护、统一术语。

## 问题与建议
| 级别 | 位置 | 问题 | 原则 | 建议 / 改后示例 |
|---|---|---|---|---|
| P0 | 首页最近动态 | 开发示例数据写死 | E1-6 诚实、#7 | 接真实数据；没有数据时显示空状态「还没有动态。上传第一个模板后，团队的改动会出现在这里。」 |
| P0 | 全部删除 | 红色按钮紧挨导出，点了直接删 | #20、F1 弹窗规则 | 移到「更多」菜单，弹窗标题点明后果，按钮写「删除 128 个资产」/「取消」 |
| P0 | 官网 vs 注册页 | 「免费注册」与「仅限邀请」矛盾 | E1-6 诚实、#29 | 两处统一：开放前写「申请试用」 |
| P1 | 资产计数 | 「共 128 个」与空表格、1/13 页码对不上 | #7、B1 | 计数和页码跟随筛选结果 |
| P1 | 导出 | 只有转圈，没有进度 | #7 加载态 | 显示进度；完成后提示 |
| P1 | 点数 | 不知道会扣多少 | #29 | 导出按钮旁显示「将消耗 20 点」 |
| P1 | 术语 | 素材 / 资产 / 文件混用 | F1 建词表、#15 | 建词表，统一用「资产」 |
| P1 | 模板引用数 | 显示 0 次引用，实际 6 个订单在用 | E1-6 诚实 | 修正计数，点击可查看引用的订单 |
| P2 | 删除工作区 | 普通成员能看到，点了才提示无权限 | #21 | 无权限时不显示 |

- 后置：「全部删除」进入「更多」菜单
