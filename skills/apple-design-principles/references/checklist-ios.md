# iOS / Apple 平台检查表（HIG 口径）

> 用于 iPhone、iPad、Apple Watch、Mac、Vision Pro 的 App 界面。网页请用 [checklist-web.md](checklist-web.md)；两端共用设计看 [platform-mapping.md](platform-mapping.md)。
> 数值来自 Apple HIG，会随系统版本变化，以 [spec-snapshot.md](spec-snapshot.md) 的核对日期为准。括号里的 #n 对应 [principles.md](principles.md)。

## 目录
B1 产品｜B2 视觉层级｜B3 字体｜B4 色彩｜B5 留白与布局｜B6 动效｜B7 无障碍｜B8 文案｜B9 补充（写作、动效、排版细则）

### B1. 产品
- [ ] 能用一句话说清这个方案解决什么问题、为谁解决
- [ ] 有明确的「不做清单」，砍掉的功能有理由
- [ ] 默认值覆盖大多数人，用户不改设置也好用
- [ ] 端到端旅程（发现→上手→日常→出错→离开）每一环都设计过
- [ ] 跨端 / 跨模块的交互和命名一致
- [ ] 空状态、错误态、加载态、离线、极端数据都考虑过

### B2. 视觉层级
- [ ] 每屏只有一个视觉焦点 / 主操作
- [ ] 眯眼看（模糊测试），层级顺序与重要程度一致
- [ ] 层级靠布局和分组表达，而不是边框、阴影、色块堆叠
- [ ] 控件与内容分离：导航 / 控件在功能层，内容在内容层
- [ ] 使用玻璃材质（Liquid Glass，见 spec-snapshot）时：只在导航 / 控件上用，无玻璃叠玻璃，内容区不用玻璃，tint 只给主操作

### B3. 字体
- [ ] 字族 ≤ 2 种（推荐系统字体：SF Pro / 苹方）
- [ ] 字号阶梯清楚，层级级数 ≤ 4
- [ ] 正文不小于平台默认（iOS 17pt），最小不低于 11pt
- [ ] 小字不用细字重（Ultralight / Thin / Light）
- [ ] 支持动态字体，放大到 200% 不截断、层级仍成立
- [ ] 中文行高适当放宽（约 1.5–1.7 倍），中英文混排加空格

### B4. 色彩
- [ ] 一个强调色（tint），只用于可交互元素
- [ ] 同一种颜色只代表一种含义
- [ ] 使用语义色，浅色 / 深色 / 高对比三种外观都检查过
- [ ] 文字对比度 ≥ 4.5:1（大字或粗体 ≥ 3:1）
- [ ] 信息不只靠颜色区分（配合图标、文字、形状）
- [ ] 在强光、弱光、不同屏幕上看过

### B5. 留白与布局
- [ ] 使用统一的间距刻度
- [ ] 组内间距 < 组间间距，分组一眼可辨
- [ ] 元素对齐到同一网格，缩进表示从属
- [ ] 尊重安全区域（Safe Area），全屏背景延伸到导航栏下
- [ ] 小屏、大屏、横竖屏、分屏都能自适应
- [ ] 形状圆角与容器同心（concentric）

### B6. 动效
- [ ] 每个动画都能回答「它在解释什么变化」
- [ ] 动效方向与手势一致，进入与退出路径对称
- [ ] 时长短（反馈类通常在零点几秒量级），不阻塞操作，可被打断
- [ ] 高频操作没有多余动画
- [ ] 开启「减弱动态效果」时有替代方案（淡入淡出代替位移、缩放、视差）
- [ ] 重要信息不只靠动画传达（有文字 / 触感反馈）

### B7. 无障碍
- [ ] 所有触控目标 ≥ 44×44pt
- [ ] 所有控件和图片有 VoiceOver 标签，朗读顺序合理
- [ ] 支持动态字体、增强对比度、降低透明度、减弱动态效果
- [ ] 不只靠颜色 / 声音 / 动画传递信息
- [ ] 手势操作有按钮替代
- [ ] 用 Accessibility Inspector 或同类工具审计过

### B8. 文案
- [ ] 标题足够短（英文 ≤ 8 词 / 中文 ≤ 12 字），一句只说一件事
- [ ] 先讲利益，再给参数佐证
- [ ] 主语是「你」，用动词驱动
- [ ] 没有空洞形容词（强大、极致、革命性、颠覆、赋能）
- [ ] 每个数字都有参照或换算，并注明条件
- [ ] 标题有记忆点，但不牺牲清楚
- [ ] 中文是重写而非直译，节奏顺口，中英文 / 数字加空格
- [ ] 按钮以动词开头；报错说清原因和下一步
- [ ] 术语全篇统一，没有无法证明的极限词


### B9. 补充检查项（来自 WWDC 写作 / 动效 / 排版讲座）
- [ ] 文案用 PACE 过一遍：这一屏的目的、下一步、使用情境、写给谁
- [ ] 删掉了填充词（轻松、快速、只需、哎呀、抱歉、请）
- [ ] 好处放在句首（先说为什么）
- [ ] 有词表：同一个概念、同一个按钮全程用同一个词
- [ ] 界面文案里没有「我们」；按钮不用「是 / 否」，写具体动作
- [ ] 动效用弹簧、可打断、尊重手势动量，默认不回弹
- [ ] 大字号下布局能从横排变成竖排，不截断
- [ ] 中西文之间有间距，标点遵守行首行尾禁则，行高 1.5–1.7
