# iOS ↔ Web 对照表

> 同一套设计要出 App 和网页、或用户问「标准是多少」时读。**区分「硬要求」和「惯例 / 推荐」**，回答时注明出处。
> 数值核对：HIG 与 WCAG 2.2 原文，2026-10-09（详见 [spec-snapshot.md](spec-snapshot.md)）。pt 与 CSS px 都是与密度无关的逻辑单位，在常见设备上 1 pt ≈ 1 CSS px，但两者出自不同规范，不要互相引用作依据。

## 目录
1. 数值对照
2. 机制对照（系统设置 ↔ 浏览器能力）
3. 组件与交互对照
4. 回答模板

## 1. 数值对照

| 项目 | iOS / iPadOS（HIG） | Web（WCAG 2.2 / 惯例） | 说明 |
|---|---|---|---|
| 点按目标 | 默认 44×44 pt，最小 28×28 pt；visionOS 60×60 pt | **AA：24×24 CSS px**（2.5.8，有间距等例外）；**AAA：44×44 CSS px**（2.5.5） | 苹果式 Web 建议主要按钮做到 44，24 只是底线 |
| 正文字号 | 默认 17 pt，最小 11 pt（macOS 13 / 10 pt） | 常用 16px 起（**惯例**，WCAG 不规定字号）；要求是能放大到 200% 不丢内容（1.4.4） | 不要说「WCAG 要求 16px」 |
| 文字对比度 | 17 pt 及以下 4.5:1；18 pt 及以上 3:1；粗体 3:1（HIG 参照 WCAG AA） | 4.5:1；大字（≥18 pt 或 ≥14 pt 粗体）3:1（1.4.3 AA）；AAA 为 7:1 / 4.5:1（1.4.6） | 两者对「粗体」的门槛略有不同，Web 以 WCAG 为准 |
| 控件 / 图形对比 | 用系统控件自动满足；自定义控件参照 WCAG | 3:1（1.4.11 AA） | 输入框边框、开关、焦点环都算 |
| 焦点 | 外接键盘 / 全键盘访问时系统焦点环 | 焦点必须可见（2.4.7 AA）；不被吸顶栏等完全遮挡（2.4.11 AA）；外观 2 CSS px 轮廓面积 + 3:1（2.4.13 AAA） | Web 用 `:focus-visible`，不要 `outline: none` |
| 文字放大 | 动态字体（Dynamic Type），到最大辅助字号布局仍成立 | 浏览器缩放 200%（1.4.4）；320 CSS px 宽重排（1.4.10）；文字间距可调（1.4.12） | |
| 自动动画 | 「减弱动态效果」开启时替换位移 / 缩放 | 自动播放超过 5 秒要能暂停（2.2.2 A）；交互动效可关（2.3.3 AAA） | |
| 闪烁 | — | 1 秒内不超过 3 次（2.3.1 A） | |

## 2. 机制对照

| 用户设置 / 能力 | iOS | Web |
|---|---|---|
| 减弱动效 | 辅助功能 → 动态效果 → 减弱动态效果 | `@media (prefers-reduced-motion: reduce)` |
| 深色模式 | 外观：深色 | `@media (prefers-color-scheme: dark)` |
| 增强对比度 | 增强对比度 | `@media (prefers-contrast: more)`；Windows 高对比 `@media (forced-colors: active)` |
| 降低透明度 | 降低透明度 | `@media (prefers-reduced-transparency: reduce)`（浏览器支持有限，需降级方案） |
| 读屏 | VoiceOver：`accessibilityLabel` 等 | 读屏软件：语义 HTML、`aria-label`、`role` |
| 字号 | Dynamic Type 文字样式 | `rem` + 浏览器字号 / 缩放 |
| 系统字体 | SF Pro / 苹方 | `font-family: system-ui, -apple-system, …`（见 [typography-zh.md](typography-zh.md)） |
| 触感反馈 | Haptics | 无对应；用视觉和文字反馈 |

## 3. 组件与交互对照

| iOS 习惯 | Web 对应 | 注意 |
|---|---|---|
| 设置改了就生效 | 同样即时保存 + 「已保存」状态；表单类批量提交才用「保存」按钮 | 离开时有未保存内容要提醒 |
| Action Sheet / Alert | 确认对话框（`<dialog>`，焦点进入、Esc 关闭、焦点归还） | 破坏性按钮样式 + 默认焦点在安全选项 |
| 滑动删除 | 行内「更多」菜单或删除按钮 | 拖拽、滑动都要有点击替代（2.5.7） |
| 标签栏 / 侧边栏 | 顶栏或侧栏，只留一套 | |
| 长按菜单 | 右键菜单 + 可见的「更多」按钮 | 隐藏手势不能是唯一入口 |
| 玻璃材质（Liquid Glass） | `backdrop-filter` 毛玻璃 | 只给导航 / 控件；文字对比度照样达标 |

## 4. 回答模板

用户问「X 要多大 / 多少」时：
1. 分平台给值：iOS（HIG）｜Web（WCAG 2.2 级别 + 准则号）
2. 标注是**要求**（AA / A）、**增强**（AAA）还是**惯例**
3. 给出苹果式推荐值（通常高于底线）
4. 附来源链接（HIG 页面、`https://www.w3.org/TR/WCAG22/#…`）
