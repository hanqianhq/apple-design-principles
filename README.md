# 苹果式产品 / UI / 文案原则手册（Apple-style Design Principles）

一份可复用的 Agent Skill：按苹果式的思路审查或设计产品方案、App / 网页界面、官网或发布会式文案（中英文）。

## 内容
- A. 核心原则清单（产品 / UI / 文案）
- B. 自查检查表
- C. 正反例改写
- D. 审查流程与输出模板
- E. 设计思想源头（Dieter Rams、Jobs / Ive、《Insanely Simple》、《Creative Selection》）
- F. 设计规范层（WWDC 设计演讲、Apple Style Guide、SF 字体与中文排版）
- G. 文案句式拆解与标题公式
- H. 实战改写练习

## 使用
把 `SKILL.md` 放进支持 Agent Skills 的工具的 skills 目录（每个 skill 一个文件夹），或直接作为审查清单阅读。

## 说明
- 只提炼方法与原则，示例全部为原创虚构产品；引用观点均注明出处，不复制苹果的文案与素材。
- 本项目与 Apple Inc. 无关联。Apple、iPhone、SF Pro 等为 Apple Inc. 的商标。
- 数值类规范请以最新版 Apple Human Interface Guidelines 和 WCAG 为准。
